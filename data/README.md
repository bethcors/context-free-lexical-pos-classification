# Data

## Dataset Source

The experiments use the **370k English Words Corpus** distributed through Kaggle:

**Ruchi Bhatia — Part-of-Speech Tagging / 370k English Words Corpus**

https://www.kaggle.com/datasets/ruchi798/part-of-speech-tagging

The dataset contains English lexical forms with automatically assigned Penn Treebank-style part-of-speech (POS) labels. The dataset used in this study contains **370,100 word types**.

## Dataset Availability

The original dataset is **not redistributed in this repository**. To reproduce the experiments, obtain the dataset directly from the original Kaggle source and comply with the terms of the source dataset.
